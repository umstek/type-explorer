# Change Log

All notable changes to the "type-explorer" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.2.1] - 2026-11-11

### Changed

- Updated dependencies and GitHub Actions; CI now runs on Node 26.
- Added the extension test to CI.

### Fixed

- Removed a broken screenshot link from the README.
- Corrected the extension ID used by the test suite.

## [0.2.0] - 2026-01-31

### Changed

- Renamed the extension package to `umstek-type-explorer`.
- Added the MIT license file.

## [0.1.0] - 2026-01-31

### Added

- Import detection for TypeScript/JavaScript.
- Module export browsing via completion items.
- Documentation panel with Markdown rendering.
- Browse any installed package.
